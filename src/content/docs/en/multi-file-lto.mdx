For a real library, all translation units that contribute to one generated package must agree on package path, target, Go version window, and ABI epoch.

## One driver invocation

The simplest multi-file build passes every source to `c2go-clang`:

```sh
c2go-clang --target="$C2GO_TARGET" \
  -fc2go \
  -fc2go-package=example.com/acme/engine \
  -O2 \
  -fc2go-emit-plan9-asm=engine.s \
  -fc2go-emit-manifest=engine.json \
  parser.c runtime.c storage.c
```

The driver compiles each source to bitcode, invokes `c2go-lto`, and emits one merged assembly/manifest pair. Cross-translation-unit inlining is enabled at optimization levels of 2 or higher.

Bind the merged output normally:

```sh
mkdir -p engine
c2go-bind \
  --pkg=example.com/acme/engine \
  --out=engine \
  --sidecar=engine.json \
  engine.s
```

## Drive c2go-lto directly

Advanced build systems can produce bitcode first and call the linker explicitly:

```sh
c2go-lto parser.bc runtime.bc storage.bc \
  --c2go-emit-asm=engine.s \
  --c2go-emit-manifest=engine.json
```

Useful options include:

| Option                         | Use                                                       |
| ------------------------------ | --------------------------------------------------------- |
| `--c2go-emit-archive=engine.a` | Package assembly and manifest members in one `ar` archive |
| `--c2go-lto-inline=0`          | Disable cross-unit inlining for diagnosis                 |
| `--c2go-escape-nonfatal`       | Report stack-to-heap escape but return success            |
| `--c2go-print-stats`           | Print pipeline statistics                                 |

Exit status `0` is clean, `1` means the escape audit found stack-to-heap escape, and `2` is a tool error. The Clang driver passes the nonfatal policy for its normal pipeline.

## Bind multiple inputs or an archive

`c2go-bind` can also merge multiple assembly inputs or accept a C2Go archive:

```sh
c2go-bind --pkg=example.com/acme/engine --out=engine a.s b.s
c2go-bind --pkg=example.com/acme/engine --out=engine engine.a
```

The binder performs exact duplicate elimination and rejects conflicts across symbols, types, globals, linknames, GC masks, callbacks, targets, versions, and ABI epochs.

## Build-system rule

Treat each `.s` and its manifest as an inseparable pair. Cache keys must include the target triple, package path, optimization level, and coordinated toolchain release. Never combine artifacts produced for different operating systems into one package without the target-specific structure generated by `c2go-bind`.

For low-level source that uses CPU instructions directly, continue with [inline assembly](/en/docs/inline-assembly/).
